> 本文按**代码**写，不按策划案写。策划案 §3 和被删掉的 ADR-0002、ADR-0004 描述的是已推翻的模型，差异集中在 §6。
>
> 只有一处实现：实验台 [LabPlayer.cs](../Project/nameless/Assets/TuningLab/LabPlayer.cs) 就是规则基准，可拖参数。正式关卡从实验台派生，不再另写一套手感代码（[ADR-0006](adr/0006-lab-single-baseline.md)）；旧的 `Assets/Scripts/PlayerMotor.cs` 已随 PR #17 删除，本文涉及它的段落一并失效。

## 0. 术语（沟通时先说清这几个词）

| 词 | 含义 |
| --- | --- |
| 折算格数 | `cells = v² / (2g)`。速度换算成"相当于从静止自由下落了多少格" |
| 挡位 | `tier = f(\|v\|)` 的**读数**，不是 buff。没有"挂上 v2 持续 2 秒"这种东西 |
| V前 | 进入冲刺那一刻，速度在冲刺方向上的投影 `v · 方向`（带正负） |
| Vd1 | 冲刺速度，`√(2·g·(4 + 0.05))`。略高于 v0，只高 0.05 格 |
| 冲刺态 | 一个持续 N 秒的状态：位移恒定、关重力、屏蔽输入、每物理步覆盖速度 |
| 互换 | 双人相撞时速度矢量与冲刺态整体交换。**没有击飞、没有硬直** |
| 红热 | 只有大框 A 的"边"会进入的状态。热 1 限时，热 2 永久 |
| 碎边 | 热 2 的边吃一记只到锻造门槛的撞击 → 那条边变成灵体框（◇）。N 条碎边的**组合**决定 A 的形态 |
| 形态 | 由碎边组合推出、不能手切：0/1/相邻2/相对2/剩1根/全碎 = 普通 / u 大炮 / L 转向器 / = ‖ 电梯 / 矛 / 灵体 |
| 装填 | u 大炮只吞"冲刺态"撞进膛口的 B。B 不可视、无碰撞箱、跟随 A，这段时间 B 的逻辑全部停用 |
| 开炮 | B 的冲刺键改成发射：`v' = √(Vb² + 一个等级间距的 v²)`，方向 = 进入方向的反向，不看 A 的速度 |

## 1. 等级（冲刺和撞击都要读它）

1 格 = 1 世界单位 = 16 px；g = 50（格/秒²）；门槛等距：**4 / 8 / 12 / 16 格**。

| 等级 | 折算落差 | 速度上限（g=50） | 谁给的 |
| --- | --- | --- | --- |
| v0 | ≤ 4 格 | 20.00 | 走、跳、冲刺 |
| v1 | 4–8 格 | 28.28 | 超过 4 格的落差 |
| v2 | 8–12 格 | 34.64 | 超过 8 格的落差 |
| v3 | 12–16 格 | 40.00 | 超过 12 格的落差 |
| v4 | > 16 格 | 无上限（名义 44.72） | 机关 / 复合 |

判定规则：

- 用**合速度 `|v|`**，不分横轴竖轴。
- **严格大于**门槛才升级，恰好等于留在低一级（`cells > 4·(i+1)`，带 0.0001 容差）。
- 冲刺速度 Vd1 = 20.12，折算 **4.05 格** → **冲刺期间是 v1**。这点很脆：`dashOverV0Cells` 改成 0 就退化成 v0，关卡里"冲刺撞得开的东西"当场全失效。

## 2. 冲刺

### 2.1 方向

四方向，不可斜冲。优先级：**竖直输入 > 水平输入 > 空中的竖直速度 > 面朝方向**（正式版没有第三档，直接用面朝方向）。

地面按下冲 = 什么都不发生，**且不消耗充能**。

### 2.2 冲刺态

冲刺不是"给一段速度"，是进入一个状态。按下后的结算顺序：

```
按下冲刺
├─ 地面 && 按下冲            → 忽略（不扣充能）
├─ 充能 < 1 / 已在冲刺中     → 忽略
└─ 方向 = 竖直输入 ? 竖 : 水平输入 ? 横 : 空中竖直速度 ? 该向 : 朝向
   V前 = v · 方向
   ├─ V前 < 0                → 冲刺速度 Vd1，结束速度 0
   ├─ V前 ≤ 20.00            → 冲刺速度 Vd1，结束速度 V前
   └─ V前 > 20.00            → 冲刺速度 V前，结束速度 V前
   位移 = 4 格（恒定），时长 = 4 / 冲刺速度
```

状态期间：

| 项 | 规则 |
| --- | --- |
| 位移 | 恒定 4 格，与速度无关 |
| 时长 | `4 / 冲刺速度` 反算（Vd1 时 ≈ 0.199 s，约 10 个物理步 @50Hz） |
| 重力 | 0 |
| 输入 | 屏蔽（转向/跳跃都不生效；跳跃缓冲要等冲刺结束才可能兑现） |
| 速度 | 每个物理步被**覆盖**成 `方向 × 冲刺速度` |
| 结束 | 恢复重力，速度换成"结束速度" |

**必须是覆盖，不能是叠加。** 保留垂直分量的话，下落 v2 的人向右冲会合成 `√(19.4² + 20²) ≈ 27.9` → 凭空变 v3，整条阶梯作废。

三档的直觉：

| V前 | 冲刺速度 | 结束速度 | 例子 |
| --- | --- | --- | --- |
| 反向 | Vd1 | **0** | 向右跑着按左冲：反向冲 4 格，冲完停住 |
| 同向、零级 | Vd1 | **V前** | 站地向右冲（V前≈0）：冲 4 格后停 |
| 同向、非零级 | **V前** | V前 | 已在 34.6 下落时按下冲：原速冲完 4 格 |

### 2.3 充能

- 只在"接触"时**上弦**：站在地面、或碰到另一名玩家任意一面。贴墙、顶天花板不算，蹭一下队友算。
- 上弦之后计时器自己走完，**离地也照常回复**（正式版 0.5 s 充满）。
- 用掉之后回到 0，必须重新接触才能再上弦。

### 2.4 冲刺期间撞东西

| 撞到 | 结果 |
| --- | --- |
| 墙 / 地 / 天花 | **冲刺态不结束**。速度每步被覆盖，所以会贴着墙把剩余时长走完（约 0.2 s），再按结束速度退出 |
| 绳等材质 | 材质返回 Bounce 时 `ReceiveBounce` 结束冲刺态并给新速度 |
| 冰块 | 冲刺态撞冰仍按 v2 规则破坏整组；冰面加速只作用于受重力的行走态，冲刺态不加速（见 §3.8） |
| 另一名玩家 | 见 §3，冲刺态被**交出去** |

### 2.5 距离变了（策划最该先看的一条）

| 方向 | 旧案（策划案 §3 / 实施阶段 P1） | 现行 |
| --- | --- | --- |
| 横冲 | 3（v1）+ 1（减速缓冲）= 4 | 4，恒定位移，**没有"缓冲段"这个概念** |
| 上冲 | 6（组合 8） | **4**，四方向共用同一个距离 |
| 下冲 | 3，只能空中 | 4，只能空中 |

上冲从 6 掉到 4 是规则改动的直接后果，不是调参：顶点速度归零，落回来时再换成约 v1 的落地速度，等于白拿 4 格高度，关卡设计要把它算进去。

## 3. 对撞（双人）

### 3.1 触发与冷却

- `OnCollisionEnter2D` 和 `OnCollisionStay2D` 都算，所以贴着不动时也会周期性结算。
- **两人共享同一个 0.18 s 冷却**（结算时同时给双方写冷却），一次接触只结算一次。
- 接触本身还给冲刺充能"上弦"——蹭队友也能回充能。

### 3.2 判定轴

用两人**中心差的主轴**（`|Δx| ≥ |Δy|` 取横，否则取竖）。只用沿该轴的有符号分量判红热，永不产生斜向。

红热用**碰撞前**的速度（正式版 `preCollisionVelocity`，实验台 `lastFixedVelocity`）：碰撞回调触发时 `rb.linearVelocity` 已经被物理解算改过，对撞时可能已经是 0。互换在实验台同样用碰撞前速度，正式版读的是当前的 `rb.linearVelocity`，差异见 §6-7。

### 3.3 互换

一句话：**A 的速度矢量给 B，B 的给 A；A 的冲刺态给 B，B 的给 A。**

冲刺态里带着"什么速度、还剩多少距离、结束后是什么速度"，**接手的人从接触点继续冲，剩余距离不重建**。

等质量、无重量差、无伤害、无硬直、不减速撞击方（因为没有"撞击方"，只有交换）。

同一条规则推出的三种手感：

| 场景 | 撞前 | 撞后 | 玩家看到的 |
| --- | --- | --- | --- |
| A 冲刺撞站着不动的 B | A 20.12 →，B 0 | A 0，B 20.12 → + 剩余冲刺 | **冲刺者原地急停，冲刺"过户"给 B** |
| 两人迎面各冲 | 20.12 → / 20.12 ← | 互换，各自沿原路返回 | 对撞 = 弹开，冲刺态也换手 |
| 同向追撞 | 后 28.28 →，前 20.12 → | 后 20.12，前 28.28 | 后面的被拖住、前面的被推快 |

### 3.4 红热与锻造（只有 A 的边）

| 项 | 规则 |
| --- | --- |
| 双人撞击前提 | 不要求谁先升到某一级，直接比 Vp（两人都在 v0 以内时 Vp 最多 800，只有完全对称的 v0 对撞够得着） |
| Vp | 同向 `\|a² − b²\|`，反向 `a² + b²`（a、b 是双方沿轴的碰撞前分量） |
| 红热门槛 | `Vp ≥ 800`（= 28.28²，即 8 格门槛的 v²，对应 `redHotTierIndex = 1`） |
| 锻造门槛 | 撞场景只看**沿接触法线**的速度分量，`v ≥ 20.00`（= 4 格门槛，`forgeTierIndex = 0`，永不高于红热门槛）。到不了什么都不发生 |
| 撞哪条边 | 双人：`EdgeFor(轴)` 给自己、`EdgeFor(-轴)` 给对方。撞场景：`EdgeFor(-接触法线)` —— 法线从物件指向自己，取反才是被砸的那一面 |
| 谁记边 | 只有 `canBeRedHot`（大框 A）真的记下来；`StrikeEdge` 开头就挡掉 B |
| 常态 → 热 1 | 只有到了红热门槛才加热；`hot = false` 的一记撞在常态边上什么都不发生 |
| 热 1 | 1.5 s 后自动回常态 |
| 热 2 | 热 1 期间**再撞一次红热级**变热 2，永久，不会再退回热 1 |
| 灵体 ◇ | 热 2 的边吃一记**只到锻造门槛**的撞击 → 砸碎成灵体；灵体不可复锻 |
| 塌框 | 热 2 的边再吃一记**红热级**撞击 → 框塌到本体，抛 `EdgeCollapsed`，**A 当场死亡**（`Destroy`，实验台没有重生） |
| 碎边组合 | 碎 1 条 / 相邻 2 条 / 相对 2 条 / 只剩 1 根 / 全碎 = u 大炮 / L 转向器 / = ‖ 电梯 / 矛 / 灵体，见 §3.5 |
| 重置 | `Teleport` 清掉全部边框（R 键重置玩家 = 复活语义）；膛里的 B 先退回膛外 |
| 外抛 | `EdgeStateChanged`（视觉 `LabVisual` 画边框）、`EdgeCollapsed`（HUD 计次）、`FormChanged`（膛内退出） |

红热是这套系统里唯一"能破坏东西"的产物，也是 A 独有的资源。B 永远不会红热。

自动化规格：`Assets/TuningLab/Tests/LabForgeTests.cs`，21 条，含「不到锻造门槛不碎框」和「撞墙只加热迎风那条边」两个反例。

### 3.5 形态（碎边组合，Issue #14）

形态不是状态机，是**碎边掩码的纯函数**（`LabForms.Of`）。四条边哪几条成了灵体，就决定 A 是什么；玩家不能手切，也不能选。

| 碎边数 | 组合 | 形态 | 朝向从哪来 |
| --- | --- | --- | --- |
| 0 | — | 普通 | — |
| 1 | 任一条 | **u 大炮** | 口 = 碎掉那条边（4 种朝向） |
| 2 | 相邻 | **L 转向器** | 开口角 = 两条碎边夹出的那个角（4 种） |
| 2 | 相对 | **= / ‖ 电梯** | 上下碎 = ‖（竖井），左右碎 = =（横井），只有 2 种 |
| 3 | 只剩一根 | **矛** | 4 种塌成 1 种：不看剩下哪根 |
| 4 | 全碎 | **灵体** | — |

- **朝向 = 最后碎的那条边**（掩码里唯一/最后决定的那一维），没有额外的"转向输入"参与。
- 边框碎了仍是实体：A 的身体碰撞箱是一整块实心盒，所以形态只改变**能触发什么机关**，不改变碰撞体积。
- 本期只做形态切换。L / 电梯 / 矛 / 灵体的具体功能还没接，只有 u 大炮做了（§3.6）。
- `Teleport`（R 重置）清空掩码 → 回普通形态；`F1` 手碎一条边、`F2` 恢复边框，用来在实验台上逐个看形态。

### 3.6 大炮：装填与发射（Issue #15）

```
B 冲刺态撞在 u 形的炮口上（谁先跑回调谁装填，另一边被 0.18 s 冷却挡住）
├─ 不装填的情况：A 不是 u 形 / 膛里已有人 / B 不在冲刺态 / B 本身在膛里
│                / B 撞上的不是炮口，而是还没碎的那几条实体边
│                → 退回 §3.3 的动量互换，一切照旧
└─ 装填：记下 B 的 v前（碰撞前速度）和冲刺轴
         B 关掉视觉与碰撞箱、改 Kinematic、每物理步贴到 A 的位置
         B 的 Update 早退：移动无效、不算在地面、不回充能、冲刺键变成"给宿主开炮"
         A 的 Update 照常走（走路/跳/冲刺都不受影响）

发射（B 按冲刺键）
   v' = √(Vb² + 2·g·间距格数)      // 间距 4 格、g=50 → √(Vb² + 400)
   方向 = 进入方向的反向（从它进来的那个口退出去），不看 A 自己的速度
   水平射出时置"滑翔"：|vx| ≥ 20.00（零级门槛）期间重力为 0，掉到零级恢复

退出装填态
   ├─ B 被射出          → 按 v' 复活在 A 外面
   ├─ A 换形态（u→L 等）→ 按进入时的 v原样退回膛外，不加速
   └─ A 塌框死亡        → 同上，先把 B 吐出去再 Destroy
```

**撞的是哪条边**：按两人中心差的主分量判（横向大就算左/右，纵向大就算上/下），和加热、动量互换用的是同一个读数。那条边是灵体 = 炮口，才吃人；口朝↑ 的炮被 B 从下面顶上来不算进膛，照旧互换。射出方向仍取进入方向的反向，所以这条判据顺带保证了"从哪个口进就从哪个口出"，四个朝向第一次各有用途。

验收口径：**B 自由落体 x 格，最后冲刺进入 A，直接射出，B 大约能到 x + 4 格**。多出来的正好是一个等级间距（`tierSpacingCells`）的落差，所以 g、间距这两个滑块动的就是这门炮的力道。

方向为什么取"进入方向的反向"：Issue #15 同时说了"不考虑 A 的速度"和"B 移动无效"，那么出膛方向只剩 B 自己那条冲刺轴可用；而验收要的是"落下来 x 格、打出去 x+4 格"，只有反向成立。（旧 `FormController` 用的是 B 的输入瞄准方向，那条输入现在已经被停用。）

### 3.7 已经撤掉的旧规则（别再引用）

- 横碰 `3（v2）+ 2（v1）+ 1` 两段击飞。
- 受击方 0.12 s 输入硬直。
- "只把速度传给受击方，不反向减速撞击方"。
- "纵向踩头不参与传递"。
- `ImpactInfo` 只在受击方抛。

正式版 `PlayerMotor` 已随 PR #17 删除，`BeginKnockback` / `ReceiveBounce` 那套一并消失。实验台里对应的是 `LabPlayer.ApplyBounce`（被竖绳等场景物件用来弹开玩家），不再由双人碰撞触发。

### 3.8 冰块（Issue #29）

冰块是 1×1 的实体关卡物件，按整数 `groupId` 编组；**0 也是普通组**，编辑器默认从 1 开始分配新组。

| 触发 | 结果 |
| --- | --- |
| 组内任意一块受到 v2 撞击 | 整组冰块一起破坏，**优先于红热**；只算碰撞前沿**接触法线**撞进去的分量，站在冰面上横向滑行不算 |
| A 的 Hot1 / Hot2 边在非承重接触 | 只破坏被接触的这一块；该边强制回到 `Normal`，不进入 `StrikeEdge` 的热 1→热 2→灵体/塌框状态机 |
| A 的红热边踩在冰块上，或冰格落在玩家脚下 footprint 内 | 不融，避免把脚下承重块融掉后摔到普通地面被制动；不同分组交界处的侧向接触同样按此处理 |
| 普通（非红热）边撞冰 | 只按 v2 规则碎整组，不给边加热 |
| 地图重置 / 复活 | 所有冰块恢复 |

**v2 撞击优先于红热**：红热边高速撞冰也整组碎；红热只处理非承重的低速接触。这是 Issue #47 的修正，避免滑行时把整组冰块一块块融掉或融掉脚下承重块。

冰面加速：

| 项 | 规则 |
| --- | --- |
| 生效条件 | 站在冰块上、受重力的行走态、按住水平方向；冲刺态和无重力状态不加速 |
| 加速度 | `a = g`；由 `v² = 2·g·s` 推得每走 4 格增加一个等级间距 |
| 松手 | 只停止加速，不施加普通地面的 `groundBrake`，保留滑行 |
| 离开冰面 | 继续由现有的 `-g` 横向空气阻力衰减 |
| 上限 | v4 名义上限 `SpeedForCells(Boundary(MaxTier-1) + tierSpacingCells)`（默认 ≈ 44.72） |

红热融冰只在 `OnCollisionEnter` 结算；贴着冰站立、之后边才变红不会融脚下这一块。冰块的关卡数据、编辑器工具和验证见 [tuning-lab-level-editor.md](tuning-lab-level-editor.md)。

手动验收（HUD 读数即可判定，不需要看代码）：

1. 站地按冲刺：速度瞬时 ≈ 20.12，等级黄 v1，位移 4 格。
2. 空中下冲：只能在空中触发；站在地面按不生效且充能不掉。
3. 冲刺撞静止队友：自己停住、队友接管冲刺并走完剩余距离。
4. 两人迎面同时冲刺：各自弹回，A 的那条边点亮红热（B 没有边）。
5. 同向追撞（28.28 追 20.12）：不点亮红热。
6. 从 12 格高自由落体砸地面：HUD 里「下」那条边进 ①；再砸一次进 ②；第三次（从 6.5 格落下，只到锻造门槛）变 ◇，边框变成几乎透明的白。
7. 边是 ② 时再从 12 格砸下去：HUD 底部出现「塌框 1 次 A 的下边」，**A 消失，相机改绑 B 且不再随距离伸缩**。
8. 按 `F1`（碎边顺序固定是 上 → 下 → 左 → 右）：第一条碎的是上边，HUD「形态」出现 `u 大炮 口朝↑`，A 仍然能走能跳能撞。
9. 再按 `F1` 碎相邻的一条：`L 转向器 开口↖`；先按 `F2` 清账、碎上下两条：`‖ 电梯（竖）`，碎左右两条：`= 电梯（横）`；碎到只剩一根：四种情况都是 `矛`（读数带上剩下哪根，形态同一个）；全碎：`灵体`。按 `F2` 恢复边框回 `普通`。
10. `F2` 清账 + `F1` 一次（口朝↑），B 从 A 上方 6 格自由落体、在最后一段按下冲刺（句号 `.`）撞进 A：B 从画面里消失，HUD A 那栏「大炮」显示已装填和 v'，B 那栏显示膛内，A 移动时 B 跟着走。
11. 装填期间按 B 的移动键：什么都不发生（B 的移动无效），B 的充能条不回满；按 B 的冲刺键（句号 `.`）= 开炮，B 从它进来的那个口反向打出去，HUD「大炮」行给出 v'。
12. 上一步的直接读数：B 出膛后最高点的**净落差**比落体段多约 4 格（一个等级间距）。把 `tierSpacingCells` 从 4 拖到 6，这门炮应当多送 2 格。
13. 水平射出（u 口朝左 / 朝右）：只要 `|vx| ≥ 20.00`，B 就不受重力、走平线；掉回零级立刻恢复下落。
14. 膛里有人时把 A 打成 L / 电梯 / 矛（继续按 `F1` 碎边）或让 A 塌框死亡：B 不加速、按进入时的速度退回膛外，不会被吞掉或跟着一起没。
15. 编辑器放 3 块同组冰 + 1 块另一组；A 以 v2 撞同组任意一块 → 3 块同时消失，另一组保留；`MapReset` 后全部恢复。
16. A 的边 Hot1 接触一块冰 → 只消失一块，HUD 该边回普通，组内其余仍在；Hot2 接触同样只融一块，不碎成灵体、不塌框。
17. 站在长冰面上按住方向 → 速度按 4 格/等级上升并封顶 v4；松手继续滑行；走下冰面后横向空气阻力让速度衰减；冰面上冲刺不加速。
18. 冰面上冲刺撞冰仍按 v2 破坏整组。

自动化：**锻造 + 形态 21 条、大炮 8 条、冰块 7 条**。冲刺与对撞的互换路径仍无自动测试，只靠上面 1–5 手动验收。

## 7. 需要拍板的五件事（原六件，第 5 条已定）

1. **撞人到底"给什么"。** 现在给的是撞击方的原速度（冲刺 = v1），所以"撞人 → 对方变 v2 → 砸 v2 墙"不成立。
   - A：保持互换，把 L1 的墙阈值降到 v1，v2 留给重力/机关（阶梯还在）。
   - B：受击方速度 = 撞击方速度再升一级。会重新引入"凭空能量"，但也把"撞击 = 升一级"这条直觉救回来。
2. **上冲/下冲是否继续和横冲共用 4 格。** 共用就要重摆所有按 6 格跳高的机关；不共用就要给冲刺态加"按方向配距离"，规则会变复杂。
3. **竖直踩头算不算对撞。** 现在算：踩上去会互换，站着的人被砸下去。拦不住的话，驮带和叠罗汉都会被这个结算搅乱。
4. **冲刺撞墙要不要打断冲刺态。** 现在不打断，会贴着墙顶完 0.2 s。
5. **炮口朝向要不要参与装填判定。** **已定并已实现**（2026-11-03）：按两人中心差的主分量定出 A 被撞的那条边，是灵体边（= 炮口）才装填，撞实体边退回普通互换。口朝↑ 的炮从此只往天上打，4 个朝向各有用途；代价正是"从背面砸过来的 B 不再被吞"（§3.6）。
6. **塌框之后呢。** 现在热 2 吃红热级撞击 = A 直接消失，没有重生、没有关卡失败判定（见 §3.4）。要么接生命系统，要么把"塌框"降级成掉一条边 + 短暂无敌。
